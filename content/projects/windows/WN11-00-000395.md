# STIG ID: [WN11-00-000395](https://stigaview.com/products/win11/v1r6/WN11-00-000395/)
## Vulnerability Discussion
Having portproxy enabled or configured in Windows 11 could allow a man-in-the-middle attack.

## Compliance Check
Check the registry key for existence of proxied ports:

- Registry Hive: `HKEY_LOCAL_MACHINE`
- Registry Path: `\SYSTEM\CurrentControlSet\Services\PortProxy\`

If the key contains `v4tov4\tcp\` or is populated `v4tov4\tcp\`, this is a finding.

Run the following command:
```
netsh interface portproxy show all
```

If the command displays any results, this is a finding.

## Remediation
Contact the Administrator to run `netsh interface portproxy delete` with elevation. Remove any enabled portproxies that may be configured.

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Check registry for portproxy configuration
Write-Output "Checking registry for portproxy configuration..."
$RegistryPath = "HKLM:\SYSTEM\CurrentControlSet\Services\PortProxy\v4tov4\tcp"

if (Test-Path $RegistryPath) {
    $ProxiedPorts = Get-ItemProperty -Path $RegistryPath -ErrorAction SilentlyContinue
    if ($ProxiedPorts) {
        Write-Output "Portproxy entries found in registry. Proceeding with removal..."
    }
} else {
    Write-Output "No portproxy registry entries found."
}

# Check netsh for active portproxy entries
Write-Output "Checking for active portproxy entries via netsh..."
$NetshOutput = netsh interface portproxy show all

if ($NetshOutput -match "\S") {
    Write-Output "Active portproxy entries found:"
    Write-Output $NetshOutput
    Write-Output "Removing all portproxy entries..."
    netsh interface portproxy reset
} else {
    Write-Output "No active portproxy entries found via netsh."
}

# Remove registry keys if they exist
if (Test-Path $RegistryPath) {
    Write-Output "Removing portproxy registry entries..."
    Remove-Item -Path $RegistryPath -Recurse -Force
}

# Verify registry is clean
Write-Output "Verifying registry portproxy configuration..."
if (-not (Test-Path $RegistryPath)) {
    Write-Output "Verification successful: No portproxy registry entries found."
} else {
    Write-Error "Verification failed: Portproxy registry entries still exist at $RegistryPath."
}

# Verify netsh is clean
Write-Output "Verifying active portproxy entries via netsh..."
$NetshOutput = netsh interface portproxy show all

if ($NetshOutput -notmatch "\S") {
    Write-Output "Verification successful: No active portproxy entries found."
} else {
    Write-Error "Verification failed: Active portproxy entries still present."
    Write-Output $NetshOutput
}

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
