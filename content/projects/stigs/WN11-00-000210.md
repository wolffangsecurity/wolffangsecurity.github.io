# STIG ID: [WN11-00-000210](https://stigaview.com/products/win11/v2r5/WN11-00-000210/)
## Vulnerability Discussion
If not configured properly, Bluetooth may allow rogue devices to communicate with a system. If a rogue device is paired with a system, there is potential for sensitive information to be compromised.

## Compliance Check
This is NA if the system does not have Bluetooth.

Verify the Bluetooth radio is turned off unless approved by the organization. If it is not, this is a finding.

> **Note:** Approval must be documented with the ISSO.

## Remediation
Turn off Bluetooth radios not organizationally approved. Establish an organizational policy for the use of Bluetooth.

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Check if Bluetooth hardware is present
Write-Output "Checking for Bluetooth hardware..."
$BluetoothRadios = Get-PnpDevice -Class Bluetooth -ErrorAction SilentlyContinue

if ($null -eq $BluetoothRadios -or $BluetoothRadios.Count -eq 0) {
    Write-Output "No Bluetooth hardware detected on this system. This STIG is NA."
    exit
}

Write-Output "Bluetooth device(s) found:"
$BluetoothRadios | ForEach-Object { Write-Output "  - $($_.FriendlyName) | Status: $($_.Status)" }

# Disable all Bluetooth radios
Write-Output "Disabling all Bluetooth radios..."
foreach ($Radio in $BluetoothRadios) {
    if ($Radio.Status -eq "OK") {
        Write-Output "Disabling: $($Radio.FriendlyName)..."
        Disable-PnpDevice -InstanceId $Radio.InstanceId -Confirm:$false
    } else {
        Write-Output "$($Radio.FriendlyName) is already disabled or not active. No action required."
    }
}

# Verify all Bluetooth radios are disabled
Write-Output "Verifying Bluetooth radio status..."
$BluetoothRadios = Get-PnpDevice -Class Bluetooth -ErrorAction SilentlyContinue

foreach ($Radio in $BluetoothRadios) {
    if ($Radio.Status -ne "OK") {
        Write-Output "Verification successful: $($Radio.FriendlyName) is disabled."
    } else {
        Write-Error "Verification failed: $($Radio.FriendlyName) is still enabled."
    }
}

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
