# STIG ID: [WN11-AC-000005](https://stigaview.com/products/win11/v2r5/WN11-AC-000005/)
## Vulnerability Discussion
The account lockout feature, when enabled, prevents brute-force password attacks on the system. This parameter specifies the amount of time that an account will remain locked after the specified number of failed logon attempts.

## Compliance Check
Verify the effective setting in Local Group Policy Editor. Run "gpedit.msc".

Navigate to Local Computer Policy >> Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Account Lockout Policy.

If the "Account lockout duration" is less than "15" minutes (excluding "0"), this is a finding.

> **Note:** Configuring this to "0", requiring an administrator to unlock the account, is more restrictive and is not a finding.

## Remediation
Configure the policy value for Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Account Lockout Policy >> "Account lockout duration" to "15" minutes or greater.

> **Note:** A value of "0" is also acceptable, requiring an administrator to unlock the account.

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Check the current account lockout duration
Write-Output "Checking current Account Lockout Duration setting..."
$LockoutPolicy = net accounts | Select-String "Lockout duration"

if ($LockoutPolicy) {
    Write-Output "Current setting: $($LockoutPolicy.ToString().Trim())"
}

# Set account lockout duration to 15 minutes
Write-Output "Configuring Account Lockout Duration to 15 minutes..."
net accounts /lockoutduration:15

if ($LASTEXITCODE -ne 0) {
    Write-Error "Failed to configure Account Lockout Duration. Ensure the Lockout Threshold is set before configuring duration."
    exit
}

# Verify the configured value
Write-Output "Verifying Account Lockout Duration setting..."
$VerifyPolicy = net accounts | Select-String "Lockout duration"
$DurationValue = ($VerifyPolicy -replace "[^0-9]", "").Trim()

if ([int]$DurationValue -ge 15 -or [int]$DurationValue -eq 0) {
    Write-Output "Verification successful: Account Lockout Duration is set to $DurationValue minute(s)."
} else {
    Write-Error "Verification failed: Account Lockout Duration is set to $DurationValue minute(s), which does not meet the requirement of 15 minutes or greater."
}

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
