# STIG ID: [WN11-CC-000085](https://stigaview.com/products/win11/v2r5/WN11-CC-000085/)
## Vulnerability Discussion
The default behavior is for Early Launch Antimalware - Boot-Start Driver Initialization policy to enforce "Good, unknown and bad but critical" (preventing "bad"). By being launched first by the kernel, ELAM (Early Launch Antimalware) is ensured to be launched before any third-party software, and is therefore able to detect malware in the boot process and prevent it from initializing.

## Compliance Check
The default behavior for Early Launch Antimalware - Boot-Start Driver Initialization policy is to enforce "Good, unknown and bad but critical" (preventing "bad").

If the registry value below does not exist, this is a finding. If it exists and is configured with a value of `7`, this is a finding.

- Registry Hive: `HKEY_LOCAL_MACHINE`
- Registry Path: `\SYSTEM\CurrentControlSet\Policies\EarlyLaunch\`
- Value Name: `DriverLoadPolicy`
- Value Type: `REG_DWORD`
- Value: `1`, `3`, or `8`

Possible values for this setting are:

| Value | Description |
|---|---|
| `8` | Good only |
| `1` | Good and unknown |
| `3` | Good, unknown and bad but critical |
| `7` | All — includes "Bad" and is a **finding** |

## Remediation
Configure the policy value for Computer Configuration >> Administrative Templates >> System >> Early Launch Antimalware >> "Boot-Start Driver Initialization Policy" to "Enabled" with "Good, unknown and bad but critical" selected.

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Define the registry path and required value
# Value 3 = "Good, unknown and bad but critical" (recommended per STIG)
# Acceptable values are 1, 3, or 8 - value 7 is a finding
$RegistryPath = "HKLM:\SYSTEM\CurrentControlSet\Policies\EarlyLaunch"
$ValueName = "DriverLoadPolicy"
$ExpectedValue = 3
$AcceptableValues = @(1, 3, 8)
$FindingValue = 7

# Check the current value before remediation
Write-Output "Checking current DriverLoadPolicy setting..."
$CurrentValue = (Get-ItemProperty -Path $RegistryPath -Name $ValueName -ErrorAction SilentlyContinue).$ValueName

if ($null -eq $CurrentValue) {
    Write-Output "Registry value does not exist. This is a finding. Proceeding with remediation..."
} elseif ($CurrentValue -eq $FindingValue) {
    Write-Output "Registry value is set to $CurrentValue (All drivers including Bad). This is a finding. Proceeding with remediation..."
} elseif ($CurrentValue -in $AcceptableValues) {
    Write-Output "Registry value is already set to $CurrentValue which is compliant. No action required."
    exit
}

# Ensure the registry path exists
if (-not (Test-Path $RegistryPath)) {
    Write-Output "Registry path does not exist. Creating path: $RegistryPath"
    New-Item -Path $RegistryPath -Force | Out-Null
}

# Set the registry value to 3 (Good, unknown and bad but critical)
Write-Output "Configuring $ValueName to $ExpectedValue (Good, unknown and bad but critical)..."
Set-ItemProperty -Path $RegistryPath -Name $ValueName -Value $ExpectedValue -Type DWord -Force

# Verify the configured registry value
Write-Output "Verifying the configured registry value..."
$ConfiguredValue = (Get-ItemProperty -Path $RegistryPath -Name $ValueName -ErrorAction SilentlyContinue).$ValueName

if ($ConfiguredValue -in $AcceptableValues) {
    Write-Output "Verification successful: $ValueName is set to $ConfiguredValue (compliant — bad drivers will be prevented)."
} else {
    Write-Error "Verification failed: $ValueName is set to $ConfiguredValue, which is not a compliant value. Expected one of: $($AcceptableValues -join ', ')."
}

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
