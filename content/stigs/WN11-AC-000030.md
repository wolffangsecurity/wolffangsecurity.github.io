# STIG ID: [WN11-AC-000030](https://stigaview.com/products/win11/v2r5/WN11-AC-000030/)
## Vulnerability Discussion
Permitting passwords to be changed in immediate succession within the same day allows users to cycle passwords through their history database. This enables users to effectively negate the purpose of mandating periodic password changes.

## Compliance Check
Verify the effective setting in Local Group Policy Editor. Run "gpedit.msc".

Navigate to Local Computer Policy >> Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Password Policy.

If the value for the "Minimum password age" is less than "1" day, this is a finding.

## Remediation
Configure the policy value for Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Password Policy >> "Minimum Password Age" to at least "1" day.

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Check the current minimum password age setting
Write-Output "Checking current Minimum Password Age setting..."
$PasswordPolicy = net accounts | Select-String "Minimum password age"

if ($PasswordPolicy) {
    Write-Output "Current setting: $($PasswordPolicy.ToString().Trim())"
}

# Set minimum password age to 1 day
Write-Output "Configuring Minimum Password Age to 1 day..."
net accounts /minpwage:1

if ($LASTEXITCODE -ne 0) {
    Write-Error "Failed to configure Minimum Password Age."
    exit
}

# Verify the configured value
Write-Output "Verifying Minimum Password Age setting..."
$VerifyPolicy = net accounts | Select-String "Minimum password age"
$MinAgeValue = ($VerifyPolicy -replace "[^0-9]", "").Trim()

if ([int]$MinAgeValue -ge 1) {
    Write-Output "Verification successful: Minimum Password Age is set to $MinAgeValue day(s)."
} else {
    Write-Error "Verification failed: Minimum Password Age is set to $MinAgeValue day(s), which does not meet the minimum requirement of 1 day."
}

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
