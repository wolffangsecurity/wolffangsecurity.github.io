# STIG ID: [WN11-AC-000040](https://stigaview.com/products/win11/v2r5/WN11-AC-000040/)
## Vulnerability Discussion
The use of complex passwords increases their strength against guessing and brute-force attacks. This setting configures the system to verify that newly created passwords conform to the Windows password complexity policy.

## Compliance Check
Verify the effective setting in Local Group Policy Editor. Run "gpedit.msc".

Navigate to Local Computer Policy >> Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Password Policy.

If the value for "Password must meet complexity requirements" is not set to "Enabled", this is a finding.

> **Note:** If the site is using a password filter that requires this setting be set to "Disabled" for the filter to be used, this would not be considered a finding.

## Remediation
Configure the policy value for Computer Configuration >> Windows Settings >> Security Settings >> Account Policies >> Password Policy >> "Password must meet complexity requirements" to "Enabled".

## Powershell Remediation Script
```powershell
# Check for administrative privileges
if (-not ([Security.Principal.WindowsPrincipal] [Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole] "Administrator")) {
    Write-Error "This script requires administrative privileges. Please run PowerShell as an administrator."
    exit
}

# Check the current password complexity setting
Write-Output "Checking current Password Complexity setting..."
$SecPolPath = "$env:TEMP\secpol.cfg"
secedit /export /cfg $SecPolPath /quiet

$SecPol = Get-Content $SecPolPath
$ComplexityLine = $SecPol | Select-String "PasswordComplexity"

if ($ComplexityLine) {
    Write-Output "Current setting: $($ComplexityLine.ToString().Trim())"
} else {
    Write-Output "Password complexity setting not found in current policy export."
}

# Enable password complexity via secedit
Write-Output "Configuring Password Complexity to Enabled..."
$InfPath = "$env:TEMP\complexity.inf"
$DbPath = "$env:TEMP\complexity.sdb"

@"
[Unicode]
Unicode=yes
[System Access]
PasswordComplexity = 1
[Version]
signature="`$CHICAGO`$"
Revision=1
"@ | Out-File -FilePath $InfPath -Encoding Unicode

secedit /configure /db $DbPath /cfg $InfPath /areas SECURITYPOLICY /quiet

if ($LASTEXITCODE -ne 0) {
    Write-Error "Failed to configure Password Complexity."
    exit
}

# Verify the configured value
Write-Output "Verifying Password Complexity setting..."
secedit /export /cfg $SecPolPath /quiet
$VerifyPol = Get-Content $SecPolPath
$VerifyLine = $VerifyPol | Select-String "PasswordComplexity"
$ComplexityValue = ($VerifyLine -replace "[^0-9]", "").Trim()

if ([int]$ComplexityValue -eq 1) {
    Write-Output "Verification successful: Password Complexity is Enabled."
} else {
    Write-Error "Verification failed: Password Complexity is not Enabled. Current value: $ComplexityValue."
}

# Clean up temporary files
Remove-Item -Path $SecPolPath, $InfPath, $DbPath -ErrorAction SilentlyContinue

# Force Group Policy update
Write-Output "Enforcing Group Policy update..."
gpupdate /force
```
